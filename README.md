# Detroit Youth Health Expo — Official Website

This repository contains the source code for the **Detroit Youth Health Expo (DYHE)** official website.

## Official website

**https://detroityouthhealthexpo.org/**

Detroit Youth Health Expo connects high school students, undergraduate students, medical and graduate students, healthcare professionals, mentors, and community partners through healthcare career exploration, mentorship, research, networking, and educational programming in Detroit, Michigan.

## About DYHE

The Detroit Youth Health Expo is dedicated to exposing high school students to diverse healthcare careers while helping them build meaningful connections with healthcare professionals. DYHE also creates opportunities for undergraduate, medical, and graduate students to mentor, present research, develop professionally, and strengthen the healthcare pipeline.
